# Synergy AI Questionnaire Demo

This is a lightweight three-phase web app demo for the Synergy M2/M3 AI platform plan.

## Flow

1. Phase 1: Quick segmentation
   - Age
   - Occupation/lifestyle
   - Main health concern

2. Phase 2: Six core questions
   - Stress
   - Sleep
   - Digestion
   - Cold hands/feet
   - Edema
   - Bowel movement

3. Phase 3: Dynamic follow-up and sample SKU suggestion
   - Shows only the most relevant follow-up questions
   - Produces placeholder sample/SKU cards for engineer discussion
   - Real SKU matching can be connected later to the product database

## Demo Files

- `index.html`
- `styles.css`
- `app.js`

Open `index.html` in a browser to review the demo.
