ROI 基本式

年度效益 = 重工節省 + RMA 節省 + 人力節省 + 停線等待節省 + 追溯時間節省

年度成本 = 硬體 + 軟體 + 導入 + 標註 + 維運 + retrain + 教育

ROI = (年度效益 - 年度成本) / 年度成本
